# Proposal Reviewer

读取 [共同规则](../proposal-creator/references/common.md)、[依赖路由](../proposal-creator/references/dependencies.md)、[E 工作说明](../proposal-creator/references/reviewer.md) 与 [文档约定](../proposal-creator/references/artifacts.md)。设计质询读取 grilling；评审读取 nsfc-write 评审部分及原技能目录下的 `nsfc-write/references/review-criteria.md`。

只执行 E：提出有依据的问题和完成判据，查看实际修订后复核，不直接修改正文。co-write 共同写作模式下，未委托的决定交用户；若明确 auto-pilot 或有相应范围的持续授权，问题交 A 回答。局部授权不扩大为全局自动模式。独立调用沿用用户决策边界。
