# 低空 2.1.3 指南应用示例

下列只是根据对话的组织示例，实际调用应读取用户提供的完整原文和正式模板。不能用本文件替代指南，不能据此声称团队已有成果，也不固定六个课题。

候选工作包：安全控制架构与失效分析；安全裕量与加速验证；数字孪生与 LVC 虚实推演；设备与典型航空器系统测评；微轻小型无人机产品认证；场景与体系耦合测评及安全管理。

重点对应：控制链生成重构、安全性要求、危害分级、裕量模型、加速试验、风险注入、跨尺度映射、知识底座与体系管理，不能只围绕几个软件指标忽略研究内容。

考核口径示例：

- 支持失效模式不少于30种、准确率不低于99%：先明确准确的评价对象、真值与样本分布，不混成检测率。
- 不少于90%置信水平、同精度、失效生成样本量相对蒙特卡洛减少不少于95%：保留三个比较前提，提出估计对象与精度定义供决定，不能用不同精度画样本优势。
- 万架次航空器与环境/交通模型并发接入：保留指南原文，澄清架次和并发的计量与负载，不自行把万架次变成万架同时飞行。
- 异常事件检测率 >99%、测试试验置信度 >95%、告警 ≤3s、归因准确率 ≥90%：各自需要对应测量，不能使用同一“准确率”代替。
- 设备关键机理一致性满足率、已知失效与新型失效类别：分别定义评价对象与判据。
- 国家标准草稿、产品认证实施方案、各软件/系统/模块：各有成果责任与验证/审查方式。

B 可找到单机飞控试验、数字孪生平台或稀有事件采样基础时，只按证据声明支撑范围。单机成果可为新任务提供基础，不直接证明体系规模能力。

C 用 nsfc-figure 画工作包、控制链、多尺度架构与 LVC 流程；有真实数据后用 nature-figure 画样本效率、检测时延、机制一致性或多面板研究基础。阈值线明确为考核目标。
