# C：科学绘图

读取 common.md、dependencies.md；只加载本图所需绘图路径。不默认先用一种工具画、再用另一种重画。

## 绘图需求

先明确：图的一句话目的、对应正文/任务、已有结果或拟开展方案、组件和关系/数据、来源、最终物理尺寸、编辑格式。先从现有材料推断，只询问无法推断且影响结构的事项。用户已确认的 brief 不重复批准。缺关系时返回 A；少量不确定信息可以画有标记的草稿，不以审美补技术。

## 路由

| 场景 | 主 skill |
|---|---|
| 申请书问题/假设关系、任务依赖、实验设计、算法流程、系统架构、技术路线、计划图 | nsfc-figure |
| 真实试验的曲线、分布、热图、性能比较、样本效率、置信区间 | nature-figure 数据路径 |
| 多面板共同支持一个科学结论 | nature-figure 多面板证据架构 |
| 明确要求论文式可编辑 SVG 架构/流程/机制 | nature-figure 手工矢量路径 |
| 明确要求 AI 概念插图/图形摘要 | nature-figure AI 路径 |

交集规则：申请书方案图默认 nsfc-figure，按图件用途而非学科名称选择。理论推导可用概念依赖图，也可不画图；无论证需要不强制配图。已有源文件优先沿用，除非用户要求转换。不能仅因“专业/漂亮”换流程。混合方案与数据若不是共同证明一个结论，优先分图；真正的多面板论证由 nature-figure 统一规划。

## 执行与验收

- nsfc-figure：读取相关排版参考，保留未压缩 .drawio，检查结构，用官方 Draw.io Desktop 实际导出并打开检查实际尺寸，检查 SVG/PNG 是否嵌入编辑源及隐藏对象。不能官方渲染时明确“XML 已验证、渲染导出未在本机执行”，状态为待视觉验收。
- nature-figure 数据路径：读取 manifest/core 与匹配参考。沿用本任务或保存的 Python/R 偏好；没有时按原 skill 询问一次。用户明确让 agent 选择时按推荐流程决定并保存。选定后按原 skill 保持绘制后端一致；运行所需源代码、文字、面板对齐和碰撞检查及视觉复核。不可用的工具明确报告。
- nature-figure SVG：按原 skill 写 brief，使用可编辑文本与元素，执行 SVG 审计及实际渲染检查。该路径不问 Python/R。
- AI 路径：只有明确请求才启用，遵守材料上传/调用授权和适用规则，保留来源与人工科学复核状态。不生成实验数据或无依据机制。

数据来自可追溯输入，不为效果筛掉不利点。指南指标仅能标为目标/参考线，不能伪造为已实现结果。模拟曲线若经授权产生，明确其假设和模拟状态。

申请书尺寸/字体服从模板，不套期刊专属尺寸。真正投稿才核对对应期刊当前要求。图题图注需要润色时调用 humanizer-zh；范围、状态、术语和定量条件不变。

## 交付

给出可编辑源、正式导出、图注、输入来源及实际完成的验收状态。A 核对图文，B/D 核对来源，E 审视图是否支持论证。只做审阅时给意见，不重画或改文件。

## 单角色调用

申请书方案关系优先 nsfc-figure；真实数据/多面板证据用 nature-figure；明确 SVG 或 AI 插图进入相应分支。没有数据不画成已有实验结果。纯示意、审阅或规划不询问 Python/R。

仅执行 C 的任务。素材及技术关系不足时给出具体缺口或有标记草稿，不扩展编写整份申请书。
