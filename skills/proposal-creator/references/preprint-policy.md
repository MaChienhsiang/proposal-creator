# 预印本与未经同行评审材料的引用政策

用于申请书中"文献池保留、参考文献表排除"的两件分离事项。核心判断：**预印本可以读、可以借鉴、可以留在检索记录里，但不能进入参考文献表，也不能承担关键证据。**

## 一、术语

- **预印本**：仅存于 arXiv、SSRN、Research Square、机构预印本库或会议投稿未录用版本，**无正式发表版**（无期刊/会议卷期页或正式 DOI）的材料。
- **发表版**：同一工作已在期刊或会议正式出版，具备可核对卷期页/文章号与出版方 DOI。
- **关键证据**：支撑核心论断（现状判断、缺口成立、指标可达性、方法有效性）的证据；反之为背景性证据。

## 二、五条硬规则

1. **双轨保存**：预印本从检索记录中**不删除、不降级为"作废"**；另建登记表（如 `preprints.md`）记录其题目、预印本标识、可借鉴要点、拟支撑的章节或技术路线、以及不可外推之处。
2. **参考文献表排除**：正式参考文献编号（`[n]`）中不得出现预印本；同一工作有发表版时，一律引用发表版并核校作者与卷期页（预印本与发表版作者常有差异）。
3. **不作关键证据**：预印本可以提示"存在某议题/某思路"，但不得据此写"某性能已达到""某缺口已被填补""国际/国内现状为……"。这类断言须由同行评审文献、标准或本项目自有基础承担。
4. **允许的用途**：撰写技术路线、方法选型、算法结构对照、指标可达性论证思路时可借鉴；写作中若必须提及，须标注 `arXiv:<编号>，预印本`，且不得升格为正文引用编号。
5. **升级流程**：预印本获得发表版后，回到出版方/Crossref 核校元数据 → 由 D 判定证据层级与支持结论 → 再决定是否立号。未完成该流程不得引用。

## 三、分工

- **D（证据）**：判定材料性质（预印本/发表版），维护登记表与文献池状态，标记"不可入表、不可作关键证据"，并在升级时重新核验。
- **A（写作）**：只用已立号条目；把预印本限定在方法思路层面；改动引用集合后核对编号连续与文献表一一对应。
- 池内候选条目（如文献池 JSON/JSONL 索引）的状态字段**不因"不入参考文献表"而改写或删除**，由登记表承担用途说明。

## 四、自检清单

- [ ] 参考文献表中无 arXiv/预印本/未录用投稿条目；
- [ ] 有发表版的工作只用发表版，作者与卷期页已核；
- [ ] 关键论断未由预印本单独支撑；
- [ ] 预印本仍见于登记表与文献池，未被删除；
- [ ] 正文提及预印本处已标"预印本"且未给编号。
