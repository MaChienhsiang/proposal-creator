# 语言语域统一（学术书面体）

用于同一章/同一节已有一段落确立的语域，需要向其余段落对齐时。目标不是"润色得更漂亮"，而是消除与学术书面体不符的口语化、营销化和拟人化表述，使全文处于同一语域。修订只换语言外壳，不动科学主张、指标原文、引用编号与事实强度。

A 在 `humanizer-zh` 之后使用本文件；两者分工：`humanizer-zh` 处理空话与模板句，本文件处理"专业内容被口语或宣传腔包裹"的问题。

## 判断原则

1. **可核查性**：句子应陈述可被文献或数据核查的事实。凡带评价色彩而无证据支撑的动词，一律降级为中性陈述。
2. **主体可指认**：主语应是"研究/方法/模型/结果表明"，而不是"测评关心""前沿已完成""我们"。
3. **强度守恒**：替换不得改变主张强度。"显著提升"若确有统计检验则保留；仅在无检验时降为"提升"。反向亦然——不得把"可能存在"改成"表明"。
4. **同节一致**：同一节内同一概念只用一个词。若 2.2 已用"研究路径"，2.1 不再用"线索"指同一对象。
5. **术语豁免**：学科固定术语、标准名称、指标原文、专有名词即使字面"口语"，也不改。

## 六类抽象规则

每类给出识别信号与改写模式；示例取自已定稿章节，只作模板，不逐句套用。

| # | 类别 | 识别信号 | 改写模式 |
| --- | --- | --- | --- |
| R1 | 营销化动词 | 标志着、跃迁、突破、赋能、深度嵌入、打造、护航、显著提升 | 降为"表明/实现/演进至/提升"；去掉"深度""全面"等程度修饰 |
| R2 | 程度副词滥用 | 大量、急剧、极大、非常、很多、一些、越来越 | 改为可计量的表述（"多类""迅速增长"）或直接删除；有数值时用数值 |
| R3 | 口语连接与主观判断 | 即便、反之、其实、显然、可以说、毫无疑问、胜任、鸿沟、抹平、搞定 | 改为"尽管/相比之下/需/差距/抑制"等中性连接与判断 |
| R4 | 拟人化与心理动词 | 关心的是、价值在于提示、值得注意的是、这一点说明、我们希望 | 改为"所界定的是/其意义在于表明/需指出/上述结果表明/本文" |
| R5 | 时态与体标记口语 | 进入 2025 年、开始被引入、正在加速转向、把…提升了 | 改为"2025 年间/逐步被引入/进一步转向/使…提高" |
| R6 | 搭配失当与量词松散 | 从…延伸到、更接近…特征、不是同一量、推进到…层面 | 改为"由…延伸至、与…更为接近、并非同一量、推进至…层面" |

## 修订流程

1. **取基准**：先读用户已认可的那一段（如本节结论段），提取其句长、连接词、动词层级与判定句式，作为全章标尺。
2. **抽样扫描**：按 R1–R6 的信号词在目标范围内全部命中，人工判定是否属于语域问题（术语豁免优先于规则）。
3. **批量替换**：逐条 `old→new` 精确替换，每条断言原文出现次数为 1；出现 0 次或多次即停下核对，不做模糊正则替换。
4. **强度复核**：逐条对照原句，确认否定、范围、时间、比较条件、数值、引用编号未变。
5. **残留扫描**：对同一信号词再扫一遍，命中为 0 才是收敛；对判定为术语的保留项，在记录中写明理由。
6. **记录**：在 `progress.md` 或 `plan.md` 留"位置—原表述—修订后—理由"表，供后续章节沿用同一标尺。

## 禁止事项

- 不为"更好看"新增论断、限定或因果解释。
- 不把长句一律切短；学术语域允许复合长句，语域问题在词汇层不在长度层。
- 不把术语改写成同义词（"可追溯"若为方法学属性则保留）。
- 不借语域修订改动指标口径、阈值、样本量、任务边界。
- 不覆盖未参与本节讨论的段落；语域统一的验收标准是"同一章读起来像同一人按同一标准写成"。

## 验收

- 信号词残留清单为零（豁免项须逐条登记理由）。
- 正文引用编号集合与参考文献条目数前后一致。
- 指标原文逐字未变。
- 用户已认可段落所确立的判定句式在新段中可复现。
