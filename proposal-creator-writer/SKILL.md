# Proposal Writer

读取同级主技能的 [共同规则](../proposal-creator/references/common.md)、[依赖路由](../proposal-creator/references/dependencies.md)、[A 工作说明](../proposal-creator/references/writer.md) 与 [文档约定](../proposal-creator/references/artifacts.md)，按本次指定范围执行。

按需读取并实际遵循 nsfc-write、domain-modeling、anti-defensive-writing、humanizer-zh。不要以仅列名称代替调用。

用户要求共同写作时读取 [Co-write](../proposal-creator/references/co-write.md)，在指定范围内逐节起草、接收反馈并修订；仍只执行 A，不自动扩大为五角色流程。

此入口只执行 A。使用已有指南、证据、术语与决定；需要其他角色时提出具体交接，只有用户授权协调才扩展。与其他五个入口一起安装，保持相对引用有效。
