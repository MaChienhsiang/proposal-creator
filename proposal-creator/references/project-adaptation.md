# Project Adaptation

本套件面向多方向理工科科研项目申请，按申报要求和实际研究方法适配。数学、物理、化学、材料、信息、机械、土木、能源、环境、地学、生物工程及交叉方向都可采用同一五角色流程；以下分类是选择工具，不是固定学科模板或专业正确性保证。

## 最小项目概况

A 从已有资料提取并写入 plan.md，不另增管理角色或空表：

- **申报背景**：资助机构、类别、年度、项目/课题/子课题层级、正式通知/指南/模板及版本。未提供的写待核实，不猜测经费、期限或限制。
- **研究对象**：问题、对象与尺度、领域术语、已有认识、拟新增贡献、学科之间的接口。
- **研究方法**：理论推导、实验、计算/数据、观测、工程研制等，可多选并逐任务指定；学科名称不直接决定方法。
- **评价依据**：官方要求、用户目标、研究自设判据分别记录。明确对应主张应由证明、实验、计算比较、观测或工程测试中的哪类证据支撑。
- **工作条件**：团队基础、数据/材料/设备/算力与可用条件、计划进度、当前模板要求的成果与预算栏目。只在相关时核实特定资质或审查要求。

已知信息足够就推进；只有缺失信息会改变当前工作时才提问。独立角色调用只读取相关概况，不要求先做全套访谈。

## 申报类型与提纲

| 项目特征 | 组织重点 | 避免误套 |
|---|---|---|
| 自由探索/基础研究 | 问题或猜想、知识缺口、创新思路、研究路径与可行性 | 不强加产品、原型、标准草稿、示范工程或性能达标率 |
| 指南任务/应用基础 | 指南响应、科学问题、任务依赖、方法、成果与验证 | 不遗漏原指南任务，也不只写指标清单 |
| 工程研发/技术攻关 | 技术瓶颈、方案权衡、接口、性能与可靠性、样机/场景试验及交付 | 不套用基础基金中“避免应用开发”的建议否定其定位 |
| 平台/工具/数据资源 | 使用对象、能力边界、复用与验证、运行维护；按实际要求写开放/共享 | 不自动追加产业化、标准或开放承诺 |
| 混合或交叉项目 | 逐任务选择论证路径，明确共同问题、接口变量和结果如何相互支撑 | 不把不同学科简单并列，也不统一套一种指标或证据标准 |

上述是研究特征，不等同于资助机构类别。同一机构可支持不同特征，最终以实际通知和模板为准。非 NSFC 项目直接依据对应机构材料；不能套用 NSFC 的页数、提纲、限项、预算、期限、评分或 AI 使用要求。

没有定向指南时，允许从研究问题和用户目标生成明确标为工作版的提纲；不能要求用户补一份并不存在的任务指南。未取得正式模板时，不宣称满足官方格式。官方没有定量指标时，以可检查的研究目标与证据判据组织，不补造数字门槛或固定论文数量。

## 按方法选择证据与评审问题

| 方法 | A/B/D 需要说明的内容，E 按主张检查 | C 的适合图件（确有需要才画） |
|---|---|---|
| 数学与理论推导 | 定义、假设、命题边界、证明路径、关键引理、特殊情形/反例；已有与拟证明分开 | 概念依赖、推导结构；不把数值示例视为定理证明 |
| 受控实验与机理研究 | 变量、对照、测量方法、样品/重复层级、混杂因素、误差与主张强度；统计设计依实际问题确定 | 机理或实验设计图、真实表征与定量结果图 |
| 计算、算法与数据研究 | 数据来源与划分、泄漏风险、比较基线、资源条件、消融/外部验证、复现与不确定性，按任务适用性选取 | 算法流程、模型结构、真实比较与误差图 |
| 仿真与数值建模 | 模型假设、边界条件、数值验证、收敛/敏感性及适用时的实证校准；区分模型内结论与现实有效性 | 模型/计算流程、收敛曲线和有来源的仿真结果 |
| 观测、现场与环境研究 | 采样时空尺度、代表性、测量质量、混杂与外推边界；相关不自动写成因果 | 采样设计、空间/时间分布、真实观测图 |
| 工程研制与系统集成 | 需求与接口、工况/载荷、验证基准、测试条件、尺度迁移、故障/可靠性及验收判据（适用时） | 技术路线、系统架构、试验方案与真实性能图 |

这些是选用检查点，不要求每个项目回答整表。纯理论课题不强制实验、置信度或仪器；计算项目不自动拥有真实数据；工程目标不冒充已实现结果。交叉项目对不同主张分别选择证据，再说明跨任务传递的条件。

## 技能与领域边界

继续调用既定写作、语言、文献与绘图技能，按 dependencies.md 的适用范围裁剪。`nsfc-*` 名称不表示所有项目都归 NSFC；非 NSFC 只复用可迁移的方法，不带入专属政策或模板。

D 根据真实研究对象查找相关领域的一手论文、标准或官方材料，核对方法和术语；B 判断既有经验在对象、尺度、条件变化后的支撑范围。已有证据不足时明确记录，不用专业术语堆叠代替依据。领域技能只在具体任务需要且可用时按需加载，不为每个方向新建常驻 agent。

领域案例仅在对象和任务相符时读取。低空案例不自动进入其他项目的术语表、工作包或指标；当前项目的指南和证据始终是写作输入。
