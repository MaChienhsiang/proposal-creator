# Proposal Figure

读取 [共同规则](../proposal-creator/references/common.md)、[依赖路由](../proposal-creator/references/dependencies.md) 和 [C 路由及验收](../proposal-creator/references/figure.md)。按本图类型只加载匹配 skill 与其要求的参考。

申请书方案关系优先 nsfc-figure；真实数据/多面板证据用 nature-figure；明确 SVG 或 AI 插图进入相应分支。没有数据不画成已有实验结果。纯示意、审阅或规划不询问 Python/R。

仅执行 C 的任务。素材及技术关系不足时给出具体缺口或有标记草稿，不扩展编写整份申请书。
