# Proposal Evidence

读取 [共同规则](../proposal-creator/references/common.md)、[依赖路由](../proposal-creator/references/dependencies.md)、[D 工作说明](../proposal-creator/references/evidence.md) 与 [文档约定](../proposal-creator/references/artifacts.md)。文献工作按领域读取 nsfc-literature 的适用方法；仅 NSFC 相关规则读取 nsfc-policy，其他项目核对应机构官方原文。

预印本、发表版与引用资格按 [预印本政策](../proposal-creator/references/preprint-policy.md) 处理：预印本保留登记、不入参考文献表、不作关键证据。

仅核验本次外部依据与引用，先支持关系后格式。缺全文如实记访问层级；不得由 DOI/标题推断全文支持。内部能力事实交 B，技术选择交用户或授权下的 A，不自动启动完整流程。
